# 方案三把 Alpine 根文件系统放进 eMMC 的 ext4 分区

**1.在 Ubuntu 终端 `xq999@...$` 检查 ext4 支持**

查看.config文件的配置中有没有运行使用EXT4
grep -E '^(CONFIG_EXT4_FS=|# CONFIG_EXT4_FS is not set)' \
  ~/imx6ull/build-kernel/.config

| 要确认的信息                                     | 用什么查看                                     |                                                    |
| ------------------------------------------ | ----------------------------------------- | -------------------------------------------------- |
| 开发板现在从哪里运行根文件系统，eMMC 有没有被挂载                | `/proc/mounts`                            |                                                    |
| 哪个设备是 eMMC、有没有分区                           | `/proc/partitions`、`/sys/.../device/name` |                                                    |
| 开发板当前能否执行分区、格式化操作                          | `command -v fdisk`、`command -v mkfs.ext4` |                                                    |
|                                            |                                           |                                                    |
| **检查命令**                                   | **为什么检查**                                 | **你的结果说明什么**                                       |
| `cat /proc/mounts`                         | 看当前正在使用哪些文件系统，避免操作正在使用的磁盘根目录              | `/` 来自 **NFS**；eMMC 没有挂载，当前系统不依赖它作为根目录             |
| `cat /proc/partitions`                     | 看内核识别了哪些磁盘和分区                             | 有 `mmcblk1`，没有 `mmcblk1p1`，说明当前没有被内核识别的 eMMC 用户区分区 |
| `cat /sys/class/block/mmcblk1/device/name` | 核对设备身份，防止操作错设备                            | `8GTF4R`，与我们之前确认的 eMMC 一致                          |
| `command -v fdisk`                         | 看是否有创建分区表的工具                              | 有，路径为 `/sbin/fdisk`                                |
| `command -v mkfs.ext4`                     | 看是否有创建 ext4 文件系统的工具                       | 没有输出，表示当前命令搜索路径中找不到它                               |
| `command -v blockdev`                      | 看是否有查询块设备参数、请求重新读取分区表等辅助工具                | 有，路径为 `/sbin/blockdev`                             |
```
Ubuntu 上的 Alpine 根目录
    ↓ 使用 mkfs.ext4 制作
rootfs.ext4 镜像文件
    ↓ 通过网络传输
开发板
    ↓ 写入 eMMC 新分区
Linux 从 ext4 分区启动
```
在Ubuntu上做ext4镜像

|部分|实际作用|
|---|---|
|`sudo`|用管理员权限操作，能够读取并保留根目录中的特殊文件等|
|`/usr/sbin/mkfs.ext4`|创建 ext4 文件系统的工具|
|`-F`|允许把普通文件作为目标来创建文件系统，**不是执行镜像**|
|`-L rootfs`|给里面的文件系统设置卷标 `rootfs`，不是修改文件名|
|`-d "$HOME/imx6ull/rootfs-ext4"`|从这个目录取文件和子目录，填入新文件系统|
|`"$HOME/imx6ull/rootfs.ext4"`|最终写入的目标镜像文件|

8.打开分区工具

- Linux 的 `fdisk` 可以创建我们这次使用的 MBR 分区表。
- U-Boot 能不能创建分区表，取决于版本和编入的命令；有些支持通过 `gpt` 等命令创建分区表。
- U-Boot 的 **`mmc part` 只是查看分区表，不是创建分区**。

| 命令                   | 作用                         |
| -------------------- | -------------------------- |
| Linux 的 `fdisk`      | 创建、修改分区表                   |
| Linux 的 `dd`         | 按字节或块复制数据                  |
| U-Boot 的 `mmc write` | 把 DDR 中的数据写入 SD/eMMC 的指定扇区 |
| U-Boot 的 `mmc part`  | 查看分区表                      |
fdisk -u /dev/mmcblk1
`fdisk` 是磁盘分区工具，`-u` 代表以扇区（sector）为单位显示和操作

| 出现的提示或操作              | 输入         | 意思                   |     |
| --------------------- | ---------- | -------------------- | --- |
| `Command ...`         | `o`        | 在内存中建立新的 DOS/MBR 分区表 |     |
| `Command ...`         | `n`        | 新建分区                 |     |
| 选择 primary / extended | `p`        | 主分区                  |     |
| `Partition number`    | `1`        | 第一个分区                |     |
| `First sector`        | `86016`    | 从 42 MiB 处开始         |     |
| `Last sector...`      | `15269887` | 到 eMMC 用户区最后一个扇区     |     |
| `Command ...`         | `p`        | 打印拟创建的分区表            |     |
|                       | w          | 把分区表写入 eMMC 并退出      |     |
得出
Device              Start       End
/dev/mmcblk1p1       86016       15269887

sync
cat /proc/partitions
会出现mmcblk1p1（在Partition number (1-4): 1就是在在 `/dev/mmcblk1` 上创建第 1 个分区，mmcblk1 + p1 = mmcblk1p1）

/dev/mmcblk1        → 访问整个 eMMC 用户区
/dev/mmcblk1p1      → 只访问其中的第 1 个分区
/dev/mmcblk1boot0   → 访问独立的 boot0 启动区
/dev/mmcblk1boot1   → 访问独立的 boot1 启动区

eMMC 用户区 /dev/mmcblk1
│
├─ 0～42 MiB
│  └─ 分区表、环境变量、已有固件等
│     不属于这次创建的 p1 分区
│

   └─ /dev/mmcblk1p1
      类型：主分区
      编号：1
      用途：接下来写入 ext4 根文件系统
